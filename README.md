# BibleGPT Deterministic Scripture 1.0.0

BibleGPT Deterministic Scripture is a local application for retrieving and
studying the bundled World English Bible (WEB) text. This product scope
centres on deterministic Scripture lookup and clearly separated study
features.

The approved payload was validated for macOS arm64 with Python 3.14.6. Exact
Scripture display uses deterministic local retrieval and does not require
embedding inference or language-model generation. Generated explanations are
optional and require a separately installed and configured local generation
service; no Ollama server or model weights are bundled.

See `VERIFY.md` for local integrity-check guidance, `RIGHTS.md` for the
recorded rights basis and naming cautions, and `PROVENANCE.md` for the source
lineage and its limits.

This metadata describes the owner-authorized public release of BibleGPT
Deterministic Scripture 1.0.0 and the exact artifact identities listed in
`ARTIFACT_IDENTITY.json`. The authorization is limited to this release; it
does not authorize deployment or production migration.
