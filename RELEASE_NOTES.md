# BibleGPT Deterministic Scripture 1.0.0

## Release scope

This release presents BibleGPT's deterministic Scripture foundation. Exact
Scripture display is local and does not require embedding inference or
language-model generation. Generated explanations are optional and require a
separately installed and configured local generation service. No Ollama
server or model weights are included.

Validated platform scope: macOS arm64, Python 3.14.6.
